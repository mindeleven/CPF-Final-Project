## 📊 Key Design Decisions

**Timeframe Parameters:**
- 5min and 4H use identical SMA ratio (20/50 = 2.5)
- Daily uses traditional Golden Cross ratio (50/200 = 4.0)
- RSI parameters consistent across all timeframes (14-period, 30/70 thresholds)
- Momentum lookback proportional to fast SMA (5min/4H: 10, Daily: 14)

**Transaction Costs:**
- Conservative 1 pip spread model
- Commission assumed minimal (IB forex)
- Fixed position size (no leverage) for consistent comparison

**Data Strategy:**
- 30 days for 5min (infrastructure testing)
- 3 years for 4H and Daily (robust backtesting)
- Separate directories per timeframe
